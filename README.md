# Wisp Engine - Game Jam Template

![Wisp Engine Logo](https://github.com/get-wisp/assets/blob/7653369238d88a6c44a8249ddcd0f562e50df98b/wisp-engine.png)

Wisp is a minimal 2D game engine built in Go, fully compatible with TinyGo and WebAssembly (WASM).
It’s designed for education, small projects, and game jams — providing a lightweight, high-performance foundation for rapid prototyping and learning how game engines work under the hood.

Wisp focuses on clarity and simplicity. It doesn’t aim to compete with large engines — instead, it serves as a lean, educational toolkit for understanding how rendering loops, input, and entity systems work at a low level.

Wisp is designed for the single-threaded WASM runtime. It uses a data-oriented, minimal allocation approach and keeps JS↔WASM crossings low.
